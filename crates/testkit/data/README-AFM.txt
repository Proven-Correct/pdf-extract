Font Metrics for the PDF Core Fonts (Helvetica only)
====================================================

Helvetica.afm in this directory is one of Adobe's 14 PDF Core Font AFM files
(Core14 AFMs), unmodified. The test kit reads its WX advance widths and its
Ascender/Descender values to place text exactly; nothing else is used.

Provenance: Adobe Core14 AFM set, originally published at
<http://partners.adobe.com/public/developer/font/index.html>. This copy was
taken byte-for-byte from the matplotlib 3.8.4 distribution
(mpl-data/fonts/pdfcorefonts/Helvetica.afm), which redistributes the Adobe
set under the notice below.
SHA-256 db772f2830fb6d000907791d8d26a12524d96943a9a739e520ee855c6b25c96f.
