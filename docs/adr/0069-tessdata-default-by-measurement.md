# 0069. The tessdata default is decided by measurement and is documentation only

## Context

Spec 0002 D-14. Design-spec section 17.2 Q2 asked for exactly this measurement. A bundled model would change the wheel's licence and size story, which is Phase 3's.

## Decision

The tessdata default is decided by unit 13's measurement and changes documentation only; the library bundles no model and O9's order is fixed.

## Alternatives considered

- **Bundle a model** - changes the wheel's licence and size story.

## Consequences

Unit 13 recommended tessdata_fast.
