# 0012. Leave the shared font cache (H7) out of this run

## Context

Decision D-7. Design spec H7 proposes an optional font cache shareable between threads (`Arc` plus a lock in place of
hayro's `Rc<RefCell<..>>`).

## Decision

H7 is not in this run. Each operation creates a fresh interpreter context and parses the fonts it uses.

## Alternatives considered

Recorded rationale: it is a performance change only, and P2/P3 are report-only in this run (ADR 0013).

## Consequences

Fonts are re-parsed on every page operation until a later run takes H7; the design spec's sharded `FontCache` and
batch `extract` workers stay out of scope with it.
