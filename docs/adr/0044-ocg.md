# 0044. No optional-content switch: hidden optional content is excluded

## Context

Decision D-28 (revision 1; compat point KP11 flipped). An earlier probe used an unsaved in-memory PyMuPDF document, which
extracts text from OFF groups; the same document saved and reopened does not, and neither does any file from disk. The
first draft therefore planned `OptionalContentMode::ShowAll` (H8a).

## Decision

No optional-content option exists in `TextOptions`. hayro's `OcgState` already implements what the oracle does for files from
disk (OFF via `BDC`, form `/OC`, OCMD, `/BaseState /OFF` are excluded; an OCG referenced without `/OCProperties` is
visible), so no fork change is needed.

## Alternatives considered

A `ShowAll` mode was rejected; recorded rationale: it would be an untested behaviour addition.

## Consequences

Oracle probes must save and reopen documents (recorded as a landmine in ARCHITECTURE.md). `tools/oracle/gen.py` always
opens fixtures from disk.
