# pdf-extract 0.1.1

The first public release. The Python API is unchanged from 0.1.0, which was
published only to an internal repository.

## Install

Wheels for CPython 3.13 and later (abi3) and free-threaded 3.14t, on
manylinux_2_28 x86_64 and aarch64 and on macOS arm64, plus the sdist and
`SHA256SUMS`. Install a wheel by its release URL, pinned by the hash from
`SHA256SUMS`; see the README's "Installing a release". No credentials are
needed.

## Changes since 0.1.0

- **Licence notices for the Rust standard library.** The extension module and
  the OCR helper link the Rust standard library statically. 0.1.0 shipped
  without its notices; 0.1.1 adds them as Part 5 of `THIRD_PARTY_NOTICES`,
  with the Rust project's own notice as `rust-std-COPYRIGHT.html` among the
  package's licence files, and lists those crates in the wheel's SBOM.
- **Release checks.** Every release now reruns the full licence check set on
  the commit being released, and verifies that the notices name every crate in
  the wheel's SBOM. A weekly job checks for new security advisories.
- **Ubuntu 26.04.** The Linux wheels are also tested on Ubuntu 26.04 with the
  distribution's own Python 3.14.
- **Migrating from PyMuPDF.** A new guide, `docs/migrating-from-pymupdf.md`,
  covers the call mapping, behaviour changes, running safely on uploaded files,
  and measuring parity offline before a single cut-over release.
